I'm **Aizen Sosuke**, a security researcher and bug bounty hunter specializing in
web application security.

## Focus Areas

- **Server-Side Request Forgery (SSRF)**
- **GraphQL security** — authorization, introspection, batching
- **IDOR / BOLA** — broken object-level authorization
- **Access control** & **business logic** flaws

## Approach

All testing is performed **strictly within the authorized scope** of official bug
bounty programs, following responsible disclosure practices. My goal is to find
high-impact issues and report them clearly so they can be fixed.
